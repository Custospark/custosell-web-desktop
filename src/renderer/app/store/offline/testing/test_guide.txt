PREREQUISITES
-------------
- Backend at http://localhost:8000
- User signed in ONLINE at least once on this device
- npm install completed

DEV VS PRODUCTION
-----------------
- Dev (npm run dev:react): IDB + RQ work; use production build for full SW test
- Production: npm run react:build && serve dist/web -l 3000
- Electron: npm run build:win — no SW, full IDB offline

QUICK SMOKE TEST
----------------
1. Online: login, load products + sales history
2. Offline: complete sale → OFF-* receipt, Pending sync badge
3. Reconnect: silent session upgrade, sync clears badges
4. Logout → offline login → products/sales still visible (IDB snapshots)

TROUBLESHOOTING
---------------
- Clear localStorage CUSTOSELL_QUERY_CACHE
- Delete IndexedDB CustosellOffline
- See docs/offline/testing.md
